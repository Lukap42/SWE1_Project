\begin{frame}{Restaurant Management Software}
\begin{itemize}

\item The purpose of the application is to provide an integrated platform that supports needs of customers, employees, management and owners of the restaurant.
\item Customers will be able to use a web application to make reservations at the restaurant as well as place orders with delivery to a chosen location.
\item Owners and management will use a separate application to track financial performance, analyse orders and reservation trends as well as manage employee schedules and assign delivery drivers. 
\item Employees using the application will be able to see delivery routes assigned to them and details of each order.
\item A centralized backend will be responsible for organizing and processing the information and coordinating communication between different users and applications.

\end{itemize}
\end{frame}
